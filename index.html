A PORTFOLIO, NOT A MOODBOARD

THE WEBSITE IS PART OF THE GAME.

Each project has its own layout, typography, palette, illustration, animation language, and interactive section. The art is bundled locally as SVG, so the visuals do not disappear because an external image service changes. Every project is plain HTML, CSS, and JavaScript and can be published directly through GitHub Pages.

Different on purposeMilitary terminal, illuminated fantasy chronicle, street-racing garage, pixel cartridge, gothic casebook, and more.
Things to actually doBuild a car, plant a garden, inspect a map, ping sonar, choose a ship, fight a training boss, and study clues.
Ready for GitHub PagesEach page uses local assets and standard browser APIs. No package install or build step.
Clear demo boundariesThese are front-end concepts, not live multiplayer services, accounts, payment systems, or backend games.
