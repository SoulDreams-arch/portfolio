## Run locally
Open `index.html` in a browser. No build tools, dependencies, external assets, API keys, or backend required.

## Publish the full portfolio on GitHub Pages
1. Create a new repository on GitHub.
2. Upload the contents of this folder (do not upload only the ZIP file).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose your default branch and `/ (root)`, then click **Save**.
6. Wait for deployment and open the URL GitHub Pages displays.

The root portfolio links to every project in `projects/`, so keep the folder structure intact.

## Important
These are original portfolio concepts, not official sites for existing games. Buttons that imply game access intentionally display a demo notice; they do not claim a real game server or account system exists. Before using a concept for a paid client, customize the copy and visual identity, verify all added asset licenses, test it on devices, and agree on the project scope.
